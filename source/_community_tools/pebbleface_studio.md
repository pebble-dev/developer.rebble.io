A visual, modern watchface editor for the Pebble smartwatch ecosystem. Design
your watchfaces in the browser and get the PBW file ready to install on your
watch with just one click.

Features:

- Visual canvas editor
- Multiple element types (rect, text, time/date, bitmaps, GPaths)
- Pebble system fonts
- Custom font support
- Monochrome preview
- Project management
- Build & export
